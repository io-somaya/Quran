# نظام التصميم والهوية البصرية — «قرءاني» (Islamic Luxury Design System)

## 1. فلسفة التصميم (Design Philosophy)
يجمع نظام تصميم «قرءاني» بين قدسية وجلال النص القرآني والهندسة الإسلامية العريقة، وبين أحدث معايير تجربة المستخدم وتصميم الويب العصري (Modern Luxury UI). يعتمد النظام على التباين المريح للعين أثناء التلاوة، والتأثيرات الزجاجية الناعمة (Glassmorphism)، والتدرجات الذهبية الفاخرة، والخطوط الطباعية العربية الأصيلة.

## 3. التيبوغرافيا والخطوط (Arabic Typography)
- **خط المصحف والآيات الشريفة:** `Amiri Quran` / `Amiri`
  - وزن القراءة: 400 و 700 مع تشكيل واضح وأرقام آيات مزخرفة بداخل رمز الزهرة القرآنية `۝`.
  - Line-height مريح: `2.4` لمنع تداخل الحركات التشكيلية.
- **خط واجهة المستخدم والعناوين:** `Cairo`
  - الأوزان المستخدمة: 400 (نصوص فرعية)، 600 (عناوين فرعية وأزرار)، 700 و 800 (عناوين رئيسية فاخرة).
- **أرقام الآيات والسور:** أرقام عربية مشرقية (١، ٢، ٣...) مع تنسيق مذهب.

## 4. مكونات واجهة المستخدم (UI Components Specs)

### 4.1. البطاقة الملكية للورد اليومي (Daily Wird Hero Card)
- خلفية بتدرج زمردي ملكي داكن مع زخرفة إسلامية هندسية بنصف شفافية 7%.
- شريط تقدم دائري ذهبي (Circular SVG Progress) يُظهر نسبة إنجاز صفحات اليوم بدقة (مثلاً: 2/2 ص أو 10/20 ص).
- زر التوثيق الفوري: زر مذهب عريض مكتوب عليه "تمت القراءة بحمد الله ✨" يعطي تفاعل حركي فوري واحتفالية لطيفة.
- ملخص الخطة الحالية وزر تعديل الخطة أو تغيير الورد.

### 4.2. لوحة قارئ المصحف (Quran Reader View)
- إطار زخرفي مستوحى من مصحف مجمع الملك فهد، مطعم بأشكال الأرابيسك الذهبية على الزوايا.
- أدوات تحكم عائمة وسلسة: تكبير/تصغير الخط، تشغيل التلاوة الصوتية، اختيار القارئ، والتنقل بين الصفحات بالأزرار أو بالسحب (Swipe) في شاشات اللمس.
- درج سفلي أو نافذة منبثقة (Drawer/Modal) للتفسير الميسر عند لمس أي آية.

### 4.3. الأذكار والسبحة الرقمية (Adhkar Cards & Smart Tasbeeh)
- بطاقات أذكار واضحة مع شريط تقدم لكل ذكر، وزر عداد ضخم يسهل لمسه بالإبهام على شاشات الجوال.
- سبحة تفاعلية دائرية تصدر نبضة بصرية (Ripple effect) وصوتاً لطيفاً خفيفاً مع عداد إجمالي وعداد للدورة.

### 4.4. منشئ رسائل وتذكيرات واتساب (WhatsApp Messenger Component)
- معاينة حية لشكل الرسالة داخل فقاعة واتساب الخضراء الشهيرة قبل الإرسال.
- زر إرسال مباشر `wa.me` يفتح تطبيق الواتساب أو واتساب ويب مع نص الرسالة مجهزاً وموجهاً للشخص المختار.
- قوالب جاهزة: (تذكير بالورد، تهنئة بإتمام الورد، تذكير بأذكار الصباح/المساء، تذكير بيوم الجمعة وسورة الكهف).

### 4.5. شريط التنقل السفلي والعلوي (Navigation Architecture)
- **سطح المكتب:** شريط علوي شفاف فاخر بتأثير الزجاج (Glassmorphism Navbar) مع التاريخ الهجري، اسم القارئ الحالي، ومبدل الثيم (نهاري/ليلي).
- **الجوال:** شريط تنقل سفلي مثبت (Bottom Navigation Bar) يحتوي على: (الرئيسية، المصحف، الأذكار، الخطط، المشتركون).

## 5. معايير الإتقان وسهولة الوصول (Impeccable Standards & A11y)
- اتجاه الصفحة بالكامل يدعم العربية الطبيعية `dir="rtl"` ولغة الوثيقة `lang="ar"`.
- التباين اللوني محقق لمعايير WCAG AAA للنصوص القرآنية، و WCAG AA لعناصر الواجهة.
- الانتقالات الحركية السلسة بـ CSS transitions (300ms cubic-bezier).
